# Quiz App

JavaScript kullanılarak geliştirilmiş basit bir quiz uygulaması.

## Özellikler

- Quiz başlatma
- Çoktan seçmeli sorular
- Her soru için 10 saniyelik süre
- Doğru ve yanlış cevap kontrolü
- Doğru cevabın gösterilmesi
- Skor hesaplama
- Sonraki soruya geçme
- Süre bittiğinde cevapların kilitlenmesi
- Quiz sonunda sonuç ekranı
- Replay ile quiz'i tekrar başlatma
- Quit ile başlangıç ekranına dönme

## Kullanılan Teknolojiler

- HTML
- JavaScript
- Bootstrap

## JavaScript Konuları

Projede aşağıdaki JavaScript konuları kullanılmıştır:

- DOM Manipulation
- Event Listeners
- Functions
- Arrays
- Objects
- Constructor Functions
- Prototype
- Methods
- `setInterval()` ve `clearInterval()`
